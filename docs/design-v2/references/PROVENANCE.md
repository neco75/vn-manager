# VN Manager — ライブラリと記録画面を分離

2026-10-03。ユーザーの選択: A案のカード一覧からC案を基にしたライブラリ詳細へ。

- 一覧: 表紙・タイトル・状況・評価。カード全体が詳細への入口。
- 詳細: 選んだ作品の表紙と、状況・評価・時間・再開メモ・感想。
- 共通ナビゲーションと一覧への戻る導線。
- 試作: 先頭カードと戻る導線を実際にクリック可能。入力や保存は画像によるイメージ。制作はImageGen組込みツール。
- 次の実装で維持する動作: 一覧の検索条件・絞り込み・スクロール位置を保ったまま詳細から戻れること。
